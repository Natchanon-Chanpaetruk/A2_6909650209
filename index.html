What I Built

ผมได้สร้างเว็บไซต์แบบหน้าเดียว เกี่ยวกับการพัฒนาเว็บไซต์เบื้องต้น โดยใช้ HTML และ CSS โดยมีการใช้ส่วนประกอบดังนี้

  • เนื้อหาหลัก 4 ส่วน: About Me, What I Built, How I Built It และ Reflection
  • ลิงก์ไปยังวิดีโอที่เกี่ยวข้อง
  • การใช้Embed videoจากyoutube

Client และ Server: มีClientเกิดขึ้นแล้วแต่ไม่มีServerเกิดขึ้น เพราะเบราว์เซอร์จะทำหน้าที่เปิดไฟล์ขึ้นมาอ่านโค้ดและแสดงผลทันทีโดยข้ามกระบวนการส่ง Request/Response ผ่าน HTTP ไป

How I Built It

ผมใช้แอพ VS code เพื่อเขียนโค้ด Html และ Css โดยมีการใช้ Extension หลักๆตามนี้

  1. Live preview จาก Microsoft ใช้ในการดูตัวอย่างของโค้ดที่เขียนมา
  2. HTML CSS Support จาก ecmel โหลดsupport html กับ css ให้ vs code ปล.ผมไม่รู้ว่าต้องใช้ไหมแต่โหลดมาไว้ก่อน

ขั้นตอนการพัฒนางานนี้มีดังนี้

  1. วางโครงสร้าง HTML อย่างsectionสำหรับหัวข้อต่างๆ
  2. แยก CSS ออกจาก HTML และจัดเก็บไว้ในไฟล์
  3. ทดสอบเปิดเว็บไซต์ในเบราว์เซอร์และตรวจสอบว่าไม่มี broken link

คลิปวิดิโอจากช่องที่ผมใช้ศึกษา(และชอบดู)แนะนำมากๆ

ส่วนวิธีการembed videoได้มาจากyoutubeตามรูปด้านล่าง(มีประโยชน์มากๆ)

Reflection

  • ความท้าทายที่พบคือการจัด layout ให้ดูเป็นระเบียบ

  • หากได้พัฒนางานนี้ต่ออยากปรับสีสันให้สวยงามและเป็นเอกลักษณ์มากขึ้นเพราะเว็บไซต์ที่ดีควรใช้งานได้สะดวกและสื่อสารตัวตนได้ชัดเจน
